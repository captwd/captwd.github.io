上一篇说清了流匹配的训练目标是一个 MSE 回归，但那个回归是有条件的：网络学的从来不是"mel 长什么样"，而是"**给定条件之后**，mel 长什么样"。这篇讲条件怎么进网络、推理时怎么放大条件的作用（CFG），以及为什么引导强度一大就会合成出伪影。

## 条件是什么：给定后所剩的不确定性

条件 c 可以一句话定义：**给定之后，目标分布所剩的不确定性之外的一切已知信息**。流 p(x₁|c) 只负责建模 c 决定不了的那部分随机性——条件压缩掉的部分模型不用学，条件决定不了的部分才是流要去"搬运"的东西。

这个定义直接解释了流匹配 TTS 的少步数可行性：条件越充分（帧级文本、说话人、情感），分布被收窄得越厉害，路径越直，ODE 越好积分。反过来说，无条件生成的流要在"任何可能的语音"之间搬运概率质量，路径高度弯曲，十步 Euler 根本积不动。

## Matcha 的条件账本

以在 ESD 情感数据集上训练的多说话人 Matcha 为例，进入 CFM 的条件一共四个（逐元素门控的 mask 不算条件）：

| 条件 | 形状 | 物理含义 | 注入方式 | 通道 |
|---|---|---|---|---|
| x_t | (B,80,T) | 流的当前状态 | 输入拼接 | 80 |
| mu_y | (B,80,T) | 音素条件经 MAS 对齐铺到帧级 | 输入拼接 | 80 |
| spks | (B,64) | 说话人查表 `nn.Embedding(10,64)` | 沿时间复制后拼接 | 64 |
| emo | (B,64) | emotion2vec 768 → 投影 MLP → 64 | 沿时间复制后拼接 | 64 |
| t | (B,) | 时间步 | sin+MLP → 每级 ResNet 调制 | — |

estimator 的输入 = 80+80+64+64 = **288 通道**。注意情感条件只用句级广播就够了：句级向量没有时间结构，天然绕开对齐问题——真要"只让某个词带情绪"的帧级控制，才需要引入时间对齐的精细条件机制。

## F5 的三个条件：换一种哲学

F5 的条件清单和 Matcha 差异很大，对着 `cfm.py` 的训练入口看：

**1. 参考 mel（infilling 填充式）**。训练时随机挑 70%~100% 的帧当"待生成区"，条件区保留真实 mel：

```python
cond = torch.where(rand_span_mask, 0, x1)    # 被遮区域清零，未遮区域保留真值
```

推理时这就是参考音频的 mel：参考段钉住原样，生成段从纯噪声流起。**音色、语速、风格、情感全部隐式打包在这一个条件里**——没有说话人嵌入表，没有风格编码器，这就是零样本克隆的全部秘密。

**2. 文本（无对齐、按位置填充）**。字符级 token 查嵌入表后，**截断/补齐到与 mel 帧数同长**，作为一路通道拼进输入。没有 MAS、没有时长预测器、没有 cross-attention——字和帧的对应关系完全交给 22 层注意力自己学。这是它和 Matcha 最本质的架构分歧。

**3. 时间步 t**。经正弦嵌入后通过 AdaLN-zero 调制每一层（下面细讲）。

特别注意：**F5 的 CFM 里没有时长条件**。生成窗多长，由 CFM 之外的一个启发式决定——按参考音频的"每字秒数"线性外推。参考音频语速异常（朗诵腔、硬截断）时外推就翻车，这是零样本克隆便利性的代价，实证分析见 [F5-TTS 零样本的时长之困](/2026/09/13/f5-tts-zero-shot-duration-and-decoupled-heads/)。

两个框架的对照：

| 条件 | Matcha（ESD） | F5-TTS |
|---|---|---|
| 内容 | mu_y，MAS 显式对齐到帧 | 文本嵌入按位置 padding，无对齐模块 |
| 说话人 | 闭集 Embedding 表 | 无显式条件，参考 mel 隐式携带，开集 |
| 情感 | emotion2vec 向量拼接 | 无，参考音频风格隐式携带 |
| 时长 | 编码器时长预测器 | CFM 内完全没有，外部启发式定长 |
| t 注入 | sin+MLP → ResNet（FiLM 式） | sin → AdaLN-zero |
| CFG | 只丢情感条件 | 丢音频 / 联合丢音频+文本 |

## F5 的 DiT：两个常见误解

F5TTS_v1_Base 的骨干配置：dim=1024、depth=22、heads=16、ff_mult=2、text_dim=512，输出 100 mel @ 24kHz（Vocos 声码器）。

```
t ──► TimestepEmbedding ─────────────────┐（供全部 22 层 + 输出层调制）
x_t | cond | text_embed 三路通道拼接 ─► Linear ─► ConvPositionEmbedding（残差式）
        ↓
22 × [ AdaLN(t 调制) → RoPE 自注意力 → gate 残差 → 调制 → FFN → gate 残差 ]
        ↓
AdaLayerNorm_Final(t) ─► Linear(1024→100) = 预测的速度场
```

**误解一：它不是"卷积加注意力"的混合结构。** 卷积只出现在门口——输入融合后的 ConvPositionEmbedding（补位置信息）和文本嵌入的 conv_layers=4；22 层块内部是纯 Transformer（attention + FFN），没有下采样上采样，序列长度全程不变。

**误解二：AdaLN 不是"最后来一个"。** 每一层块开头都有 AdaLayerNorm：t 经 SiLU+Linear 吐出 **6 组参数**（attention 支路的 shift/scale/gate + FFN 支路的 shift/scale/gate），LayerNorm 本身不带仿射参数，尺度由 t 现场生成。同一个 t_emb 在 22 层里被逐层重新消费——"现在流到第几步"这个信息层层刷新。最后那个 AdaLayerNorm_Final 只是这套制度的终站，出速度的是它后面的 Linear(1024→100)。

顺带一个值得记住的模式：**零初始化残差分支**。DiT 的 gate_msa/gate_mlp 初始 ≈0，训练起点每个块近似直通、随训练逐渐"打开"。同一个思想在别处还有两个实例——把 Mamba2 塞进 Matcha U-Net 时用的 LayerScale(1e-6)（见[双向 Mamba2 集成手记](/2026/09/11/integrate-bidirectional-mamba2-into-matcha-tts/)），以及 ConvNeXt V2 的 GRN。深层生成网络稳定训练的公共底座之一。

## CFG：两种实现，一个等价条件

训练时按一定概率把条件置零，等于免费得到同一框架下的无条件模型；推理时对两个输出做线性外推：

```
out = out_uncond + s · (out_cond − out_uncond)      s > 1 = 放大条件方向
```

"外推"发生在哪一步，产生两种实现：

```
逐步引导（标准）：                     整条外推：
for i in 1..n:                        out_c = ODE积分(条件=c)   ← 完整跑一遍
    v_c = f(x, t_i, c)                out_u = ODE积分(条件=0)   ← 完整跑一遍
    v_u = f(x, t_i, 0)                输出 = out_u + s·(out_c − out_u)
    x += dt·[v_u + s·(v_c − v_u)]
```

**等价条件：ODE 对条件线性**（v = A(t)x + b₀(t) + B(t)c）。此时解对 c 是线性的，"先组合再映射 = 先映射再组合"，两种做法严格相同。神经速度场强非线性，等价性破缺，破缺的方式才是关键：

- **逐步引导是闭环**。每一步都把"被引导后的位置"重新喂回网络——速度场只在训练见过的区域（数据附近）有意义，轨迹歪了，下一步问场时自然被拉回来。s 大只是"贴得更紧地往条件方向偏"。
- **整条外推是开环**。两条 ODE 各自规规矩矩积分完毕、落在合法数据上，落地后的线性混合**再没有被任何网络检查过**。

## 大 s 为什么会出伪影：流形与弦

把几何图像画出来：合法 mel 只占频谱空间里极小、极弯曲的一小片——**数据流形**，像三维空间里的一张薄皮。生成模型学到的是"往皮上落"。而线性外推走的是笔直的弦：弦的两端（两次采样的落点）在皮上，**弦的延长线悬在皮外**。s=2 时输出 = 2·out_cond − out_uncond，正是沿弦往外飞。

类比照片：两张真人照做 50/50 平均，中间脸还大致像人（插值勉强留在皮附近）；做 2A−B 外推——把 A 相对 B 的差异再放大一倍——五官比例就畸变进"恐怖谷"。**"像真实数据"是非线性约束，线性运算不尊重它**。音频上对应的症状就是频谱过饱和、伪影——引导强度档位实验（s ∈ {1.0, 1.5, 2.0, 3.0} 逐档试听）在大 s 档能明确听出来。

还有一个实现细节值得单独立牌：**两条分支要共享起点噪声**。如果 out_cond 和 out_uncond 的 ODE 各自从现采的独立噪声出发，差值里就混着"两份独立噪声各自生成结果的差"——接近随机的波动，也被 s 一起放大，等于往引导信号里掺方差。标准做法是画一次 z 传进两支，让差值里只剩条件的作用。
