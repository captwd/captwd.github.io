300M 量级语音模型学习率速查：一个窄带里的两个世界

2026-10-02 · captwd

扒几篇同量级（200M–400M）语音生成论文的超参表，会发现一个安心的现象：优化器几乎都是 AdamW + warmup + cosine/衰减，峰值学习率挤在 1e-4 到 5e-4 的窄带里。300M 上下的模型，2e-4 附近是安全牌。但这张表只对了一半——另一半藏在 batch 的单位里。

同一个数字，两个世界

有的论文按 token 计 batch（LM 系），有的按帧计（E2/F5 一族的流匹配骨干，一帧几万样本），有的按句计。学习率和有效 batch 是绑在一起生效的：按帧计的一个"batch 64"，折算成梯度样本量可能是按句计的几十倍。所以"照抄别人的学习率"必须连单位一起抄，否则数字相同、含义完全不同。线性缩放规则在这里仍然是大方向：batch 翻倍，学习率跟着往上挪一点。

几条实战锚点

  • warmup 占比常见 1%–5%，小数据集别省——前几百步的抖动对 mel 谱这样的逐帧目标很敏感。
  • cosine 衰减到峰值的 1/10 左右收尾，比直接衰减到 0 稳，后期重震荡少。
  • 换骨干不等于换学习率：U-Net 换成 DiT 后，同一 LR 下的早期 loss 曲线形状会变，先跑几百步看斜率再定去留。
  • 8 卡数据并行时，LR 按全局 batch 算，别按单卡 batch 算——这是最容易犯的记账错误。
这张速查的用法是"先落在窄带里，再看曲线微调"，不是"窄带里随便挑"。学习率判断失误的账，我记过一次，不想记第二次。
