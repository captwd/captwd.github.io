PMFESM2蛋白质统计势模型架构

给蛋白距离预测注入统计势：想法与模型架构

2026-09-13 · captwd

深度学习做蛋白质结构预测已经很强了，于是就有个老问题：还需要显式地注入物理先验吗？ 比如从 PDB 里统计出来的统计势（statistical potential of mean force, PMF）。这篇不谈结果，只记一下我在这件事上的想法和模型架构。

一、想法：把”注入有用”拆成三笔账

直接从 baseline 跳到”注入真实 PMF”，其实同时改动了三样东西：

  • 架构：多了一个注意力模块，容量变大了；
  • 机制：多了一条偏置信号进入注意力——不管它的数值是什么，都存在一个结构归纳偏置；
  • 内容：这条偏置携带了物理知识（氨基酸对 × 距离的能量偏好）。

这三者在任何”加 vs 不加”的对比里都是混在一起的，所以单看总分根本不知道收益来自哪里。我的想法是设计四个每次只变一个的条件，把账拆开：

条件 变化 逐差得到
Baseline 无轴向注意力、无注入 测量原点
Axial, zero bias 加轴向注意力，偏置固定为 0 架构（模块容量）
Shuffled PMF PMF 的氨基酸标签随机置换 机制（有偏置路径、无内容）
True PMF 完整统计势 内容（氨基酸特异的物理）

于是有一条加性路径分解：

Δtotal = Δarch + Δmech + Δcontent
  • Δarch = P@L(axial,0) − P@L(baseline)
  • Δmech = P@L(shuffled) − P@L(axial,0)
  • Δcontent = P@L(real) − P@L(shuffled)

要强调：这是操作性、路径依赖的分解，不是唯一的因果划分。打乱对照是整个设计的命门——它只破坏”氨基酸 ↔ 能量”的对应，保留沿距离方向的分布形状，所以如果 Δcontent ≈ 0，就说明模型消费的是注入路径而不是物理内容。

二、模型架构

整体是一条”序列 → 冻结的 ESM2 → 成对表示 → 距离分布”的流水线，外加一条从 PDB 统计出来的 PMF 分支。

1. 输入与骨干

输入是氨基酸序列。骨干是一个冻结的 ESM2 语言模型（强版 650M、1280 维；轻版 35M、480 维），逐残基 embedding 预先抽取并缓存。冻结的好处是省显存、训练稳定，也把”骨干本身会不会变”这个变量固定住。

2. 1D n-gram 编码器

用 3/5/7 三种窗口的一维卷积，捕捉不同尺度的局部序列模式。

3. 1D → 2D：外和展开

把每个残基的 1D 表示做 outer sum 得到成对表示，再加上相对位置编码。这一步把”每个残基”的信息变成”每对残基”的信息。

4. 三角乘法块

接 4 层 AlphaFold 风格的 triangle multiplication + 前馈网络。三角块的直觉是：如果 (i,j)、(j,k) 的关系已知，就能推断 (i,k)，从而让成对表示在几何上自洽。

5. 轴向自注意力

在成对表示上做行/列方向的轴向自注意力。这个模块只在”注入条件”下启用——它也是”架构贡献”的来源，所以必须能被单独开关。

6. 距离头（37-bin）

最后映射到 37 个 bin 的距离 logits，期望距离 = Σ softmax(logits)_b · bin_center_b。用分布而不是单点回归，是因为接触预测关心的是整个距离分布。

7. PMF 分支

另一条支线从非冗余 PDB 结构出发：Cβ 提取 → 37-bin 统计 → 逆玻尔兹曼 → 得到能量谱 E(37, 20, 20)。它的 bin 边界必须和距离头的 bin 严格对齐，否则先验和模型输出会错位。

三、统计势（PMF）怎么建

  • 来源：PISCES 非冗余 cull（序列同一性 ≤15%、分辨率 ≤2.5 Å、R-factor ≤0.3、仅 X-ray、链长 ≥40）。

  • 原子口径：Cβ–Cβ（Gly 没有 Cβ，退化为 Cα）。这样和 trRosetta 的 dist 字段、CASP 接触定义、AlphaFold2 的 distogram 口径一致。

  • 分箱：36 个 0.5 Å 的 bin 覆盖 [2, 20) Å，外加一个 far bin（≥20 Å）。

  • 逆玻尔兹曼：

    E[aai, aaj, b] = − log [ P(r_b | aai, aaj) / P(r_b) ]

    对称化后截断到 ±4；能量越低越有利，注入时用 −E。

  • 细节：只统计序列间隔 ≥2 的残基对（排除 i,i+1 这类由键长决定的近邻对）；伪计数 λ=1.0。

四、四种注入机制

所有注入变体共享一个统一形式 E = exp(log_scale) · E_pmf + ΔE，其中 E_pmf 是冻结的统计势，ΔE 是可学习残差。

机制 层级 做法
软查表 Soft lookup 注意力 用预测距离分布对 PMF 取期望能量 E_ij = Σ_b p_ij(b) · E_pmf(ai,aj,b)，−E 作为注意力偏置
静态偏置 Static bias 注意力 一张与距离无关的氨基酸对倾向表，零额外计算
特征门控 Feature gating 特征 把期望能量通过一个可学习 gate α 融合进成对表示
物理能量损失 损失 L_phys = relu(E_soft − E_true − margin)，惩罚”预测分布比真实结构能量更高”

每种真实 PMF 机制都配一个同路径的打乱 PMF 对照，这样机制和内容才可比。

五、表示层面的旁证（想法）

除了预测指标，我还想从表征上看模型到底怎么用这条偏置。做法是算模型成对表示（距离头输入）与 PMF 能量谱的线性 CKA，以及各条件之间的表征相似度。直觉上：

  • 如果模型真的把 PMF 当知识用了，表征应该和 PMF 能量谱有可观的对齐；
  • 如果只是把偏置当”路径”消费，那么内容交换（真实 ↔ 打乱） 引起的表征变化，应该小于 机制开关 引起的表征变化。

这是一个相关性的旁证，不能单独当因果结论，但和预测层面的匹配对照互补。

小结

  1. 想验证”注入有没有用”，一定要有打乱对照和架构对照，否则分不清架构、机制和内容。
  2. 统计势要建得和模型逐 bin 对齐，先验才不会和输出错位。
  3. 注入可以发生在不同层级（注意力 / 特征 / 损失），但每种都要配自己的匹配对照。
  4. 表征分析（CKA）是预测指标之外的一条旁证：看模型对”内容”和”机制”的反应谁更大。
