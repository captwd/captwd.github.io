本地项目 `D:\myblog3d`，独立于旧 Hexo 博客 `D:\myblog`。

## 预览

运行 `npm start`，打开 http://127.0.0.1:8137/ 。需要 HTTP，不能双击 file://。

## 三维音乐山脉

### 全屏声景与独立笔记模块

首页是一屏高的沉浸式音乐地形，同时恢复小型环绕文章卡片与藏在山脊上的文章光点。研究笔记的完整列表仍放在独立的 `notes/index.html`，通过顶部导航或右下角入口进入。笔记页使用不透明背景和普通文章卡片，播放器缩为小条。

地形宽度由 53 增至 82、纵深由 82 增至 110，频谱高度显示系数由 13 增至 18.5；桌面相机默认视距 49（上一版文章环廊为 88）。前景延伸出屏幕边缘，近大远小更明显。频谱依然由真实音频驱动；高度系数只是视觉尺度，不改变声音增益。

- 拖动山脉可完整环视 360°；滚轮或右上角“＋／−”调节视距，范围为默认距离的 0.8–1.65 倍。“复位视角”也恢复缩放。
- 文章卡片和山脊光点绑定 `landscape.sound.start` 的源音频时间戳，按与频谱相同的时间映射在纵深方向流动；进入远处、经过前景后淡出并离开画面。每篇文章在指定乐句处出现，不再按固定周期重复。局部时间拉伸时沿同一映射移动。暂停音乐或固定编辑窗口会一起暂停位移；初次播放前随无声地形预览流动。
- 卡片面向读者、使用与地形相同的透视相机，保留近距离相机与缩放。底部箭头可召回错过的文章，重新附着到当前窗口的一段声音并转到面前；不跳播音乐，召回后仍继续流走。卡片显示浏览进度。
- `landscape.frequency` 决定频率锚点，`landscape.sound` 配置乐句起止时间、标题与阅读意象。悬停／键盘聚焦时显示声音坐标与短句，连线、山坡色块和标记一起高亮。这些联系是人工编排的声音意象，不是音乐或文字的自动语义分析。导入自己的音乐时按总时长映射坐标，并改为明确的本地音乐提示。
- “隐去卡片”保留山脊链接；进入声音编辑会收起两种文章入口，关闭编辑后恢复。桌面卡片尺寸比旧展厅更小，山脉保持铺满视口。
- 研究笔记页按“生成模型／语音训练／站点手记”筛选，筛选也影响返回首页后的文章入口。正文的“定位这篇笔记”返回 `#story-<slug>`，旋转到对应文章并点亮它的山峰；定位时显示全部主题。
- CSS3D 与 WebGL 是分层渲染，普通卡片和光点以少量射线采样判断山体遮挡，完全覆盖时隐藏对应链接；选中的卡片、连线和抬高的导航灯标优先保证可读，但仍会随波形离开视野。卡片仅限制最大尺寸，不固定位置，不做逐像素混合遮挡。
- 点击山脉文章入口后，相机先用约 850 ms 靠近该山峰，再展开阅读页。桌面正文在右侧，左侧保留同一声音地形；窄屏改为顶部声音窗口。返回或 Esc 恢复进入前的相机视角，召回对应文章；音频继续使用同一个实例。
- 文章页从真实 `h2` 生成章节路径和锚点。滚动同步更新目录、章节名称、地形高亮与空间意象的进度；文末保留相关笔记。“专注阅读”隐藏地形并居中正文。“听这段乐句”从绑定片段开始播放，到片段末尾暂停；下一次整曲播放恢复正常传输。
- `landscape.theme` 有 `flow`（粒子沿轨迹汇聚）、`guidance`（条件方向与偏移）、`spectrum`（频谱光线）、`wire`（线框地形）四种视觉随笔。它们叠加在实际频谱上，没有运行模型或改变音频；桌面最多 160 个点和线段、手机最多 80 个，尊重减少动态效果设置。
- 浏览最远进度和章节锚点仅保存在当前浏览器的 localStorage；笔记页“继续上次”可回到相应章节。进度表示页面浏览位置，不表示已理解或实际阅读时长。
- 顶部或播放器“实验室”进入声音实验室；底部“编辑声音”或点击山坡打开局部声音雕刻，右键收起。初次打开页面不自动播放音乐。
- 手机使用更远的相机，独立笔记页改为单列；WebGL 不可用时提供二维波形。笔记页隐藏声音画布并停止地形绘制，保留音频与播放器。

新增文章时，在 `js/posts.js` 追加文章与主题元数据，并建立对应的 `posts/<slug>/index.html`。章节导航和相关笔记会自动连接；未配置 `landscape` 时使用首个标签作为主题。

### 音乐地形

默认是全页背景模式，内置一首完整的轻松钢琴纯音乐《Gymnopédie No.1》。录音由 Teknopazzo 上传至 Wikimedia Commons，源页面标注 CC0 1.0，详见 `audio/CREDITS.md`。MP3 与真实振幅包络均保存在本地，播放无需连接外部音乐网站。

背景是透视相机下的真实网格地形，横向对数频率、纵深时间、山高频谱能量。采用坡面光照、细网格、等高线与远雾。频谱由同一 MP3 解码到 16 kHz 后，用 2048 点 Hann 窗 FFT 分析，约 10 帧／秒、64 个频带，量化为 8 位保存。画面取前 84% 的对数频带范围（约 60 Hz–3.5 kHz），聚焦钢琴主要结构；音乐仍播放完整频率范围。

背景显示一个 32 秒的移动时间窗。首次点击前是无声山脉预览；播放后实际音乐进度驱动地形向前流动。鼠标指向山坡显示时间与近似频率，射线与实际网格相交来确定点击位置，点击后跳到对应时间继续播放。“环视”工具下拖动背景改变视角；播放器“复位视角”恢复初始角度。手机上选段／环视允许纵向滚动，拉伸工具捕获拖动操作。

### 直接雕刻一段背景音乐

- **选段（S）**：拖过山脉选择 0.2–12 秒的片段，选中区域变成紫色；起点／终点手柄可以调整边界。也可点击“选中 5 秒”快速开始。进入选段操作时暂停音乐并锁定当前地形窗口。
- **拉伸（R）**：拖动紫色选段，横向改变时间倍率 0.6–1.8×，纵向改变振幅 −12 至 +6 dB；拖动终点手柄沿地形时间方向拉伸。面板上的两个滑块提供相同操作，手柄支持方向键。
- 松手后仅试听选段；“试听这一段”／回车可以重听。底部主播放器继续播放整首音乐，并保留当前片段的变形。
- 只处理当前选段。WSOLA 尽量保持音高，变形前后的部分使用原始解码采样；拼接边界使用 5 ms 渐入／渐出。画面用同一时间映射拉伸地形，并根据选段增益调整频谱高度，未重新分析 WSOLA 输出频谱。
- “撤销变形”保留选段并恢复原声尺度；选段行的 × 取消选段。在山脉或面板上右键、按 Esc、点击面板右上角 ×，都可以收起操作面板和选段标记，保留已经完成的声音变形；单击山脉会重新打开编辑面板并从点击位置播放，也可点击底部播放器“编辑声音”打开。收起后拖动可环视，拖动结束不会触发打开面板或跳播。当前支持一个活动选段，选择新片段会替换之前的变形。变形仅在本次浏览会话中有效，不改写音乐文件。

### 鼠标光粒

鼠标移动留下薄荷绿与紫色光粒，落在山体时沿接触点上浮；点击／试听产生粒子爆发和扩散光环，拉伸时产生紫色反馈。所有效果均使用有上限的 Three.js 对象池：桌面 300 点、手机 140 点和 4 个复用光环；“光粒”按钮可以关闭。系统减少动态效果时不生成拖尾或光环。

左右方向键前后跳 5 秒，空格暂停／继续；底部播放器可以查看与拖动整首音乐进度、调整音量。默认音量 25%，普通播放结束后循环；满足下方隐藏结尾条件时停在曲末。

### 隐藏结尾

首页从 0 秒开始完整连续播放一遍，在音频引擎自然发出 `ended` 时才可能显示“一曲终了，你还在等什么呢”。按实际音频进度累计覆盖范围，并核对真实时长、音源、音频版本、音量、静音状态和播放速度；不能通过跳到曲尾触发。

- 播放期间的点击、按键、滚轮、触摸／拖动起点、输入或切换页面都会取消本轮资格；暂停、跳播、音量／倍速变化、音源变化、编辑、错误及播放中断也会取消。单纯移动鼠标不影响资格。
- 开始播放前的初始缓冲不算中断；开始实际播放后重新缓冲会取消本轮资格。资格只保存在本次浏览会话，刷新不会继承。
- 满足条件后停在自然曲末，山脉用 6.5 秒逐渐平缓、粒子与文章淡出，留出 4.2 秒静默画面后再渐显文字；操作页面后收起文字、恢复地形。未满足条件则正常循环，下一轮从头连续播放可重新取得资格。没有预览参数或强制解锁入口。减少动态效果时立即显示静态结尾。

背景音乐在站内文章切换时继续播放。进入实验室会暂停音乐，返回时恢复此前的播放位置；实验室语音与背景音乐互斥。隐藏标签页时音乐继续，WebGL 渲染暂停。减少动态效果时禁用无声预览流动，仍能显示实际播放位置。

播放器“导入”支持 40 MB、10 分钟以内的本地音频。音频在浏览器解码，频谱在 Web Worker 中计算，不上传；“↶ 钢琴”恢复内置音乐。WebGL 不可用时提供二维背景波形。

`serve.mjs` 支持 Content-Length、Accept-Ranges 与 206 音频分段响应，保证 MP3 可以准确定位播放。

## 实验室交互

- 点按画布：从该位置试听约 1.6 秒；拖动框选，松开后试听选段。
- 选择边界：拖动两个发光手柄；也可以 Tab 到手柄后用左右键微调。画布上的左右键移动整个选段，空格播放／停止。
- 拉伸工具：横向拖动画布改变时间尺度，纵向拖动改变振幅，松手后试听。
- 时间拉伸：0.6–1.8 倍，仅作用于选段。WSOLA 改变时长并尽量保持音高；画布对应部分的时间宽度同步变化。
- 振幅：选段的播放增益与波形高度同步变化。下载按钮导出变换后的 PCM16 WAV。
- 频谱：2048 点 Hann 窗 FFT，112 个时间帧、44 个对数频带（60 Hz–min(10 kHz, Nyquist)）。横轴时间，纵深频率，高度和颜色能量。
- 生成路径：固定高斯噪声点云与真实语音采样点线性插值。仅为概率路径几何示意，没有模型推理、训练或学习到的 latent 空间。
- 旋转：切换工具后拖动；重置按钮恢复视角和声音参数。
- 喜悦／悲伤：现有 Matcha-TTS 模型样本；支持导入不超过 30 MB、60 秒的音频，支持最长 12 秒本地录音。

所有音频处理在当前浏览器本地完成。不会自动播放，不会自动申请麦克风权限。

### 研究笔记发现与订阅

研究笔记按日期从新到旧显示。搜索框会在首次输入关键词时读取站内文章正文并在浏览器本地建立索引；年份与主题筛选可以组合。文章页提供复制链接，并在浏览器支持时显示原生分享按钮。

RSS 与 Atom 订阅源、站点地图和 `robots.txt` 由 `npm run generate:site-data` 从 `js/posts.js` 生成。新增文章后运行此命令并提交生成的 `rss.xml`、`atom.xml`、`sitemap.xml` 与 `robots.txt`。站点规范域名为 `https://captwd.github.io/`。

## 边界与降级

波形对立体声显示第一声道，播放、时间拉伸和导出保留原声道数。波形与频谱为显示而降采样；拉伸后的画面按时间映射原始包络，并非逐采样重绘 WSOLA 输出。WSOLA 不是神经语音模型，复杂片段在大倍率下可能出现处理痕迹。

实验室场景稳定后停止空闲绘制，隐藏页面时暂停实验室语音；音乐背景按 30 fps 绘制，页面隐藏时停止绘制。WebGL 不可用时使用二维波形，并禁用三维视图。文章页压暗场景并显示小型播放器。
